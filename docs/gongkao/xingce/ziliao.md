# 资料分析

> 资料分析是"背完就能拿分"的模块，公式必须先默写出来，再谈速度。

## 一、核心公式

### 1. 增长率

```
增长率 = 增长量 ÷ 基期量 = 现期量 ÷ 基期量 − 1
```

**例**：某市 2025 年 GDP 3200 亿元，2026 年 3520 亿元。
增长率 = (3520 − 3200) ÷ 3200 = **10%**

---

### 2. 增长量

```
增长量 = 现期量 − 基期量
       = 基期量 × 增长率
       = 现期量 × 增长率 ÷ (1 + 增长率)
```

**例**：2026 年某企业营收 1200 万元，同比增长 20%。
增长量 = 1200 × 20% ÷ 1.2 = **200 万元**（基期即 1000 万元）

> 💡 只给现期和增长率时，用第三个式子，别先去算基期。

---

### 3. 基期量

```
基期量 = 现期量 ÷ (1 + 增长率)
```

**例**：2026 年规上工业增加值 660 亿元，同比增长 10%。
基期 = 660 ÷ 1.1 = **600 亿元**

---

### 4. 现期量

```
现期量 = 基期量 × (1 + 增长率)
```

**例**：2019 年某县财政收入 500 亿元，年均增长约 8%，则 2020 年约为 500 × 1.08 = **540 亿元**

---

### 5. 间隔增长率

```
间隔增长率 = r₁ + r₂ + r₁ × r₂
```

**例**：2024 年增长 5%，2025 年增长 8%，则 2025 年比 2023 年增长：
5% + 8% + 5%×8% = **13.4%**

> 💡 别直接加 13%，乘积项那 0.4 个百分点常是选项分界。

---

### 6. 年均增长率

```
(1 + r)ⁿ = 现期量 ÷ 基期量     （n 为间隔年数）
```

**例**：2019 年 100 亿元，2024 年 161 亿元，间隔 5 年。
(1+r)⁵ = 1.61 → 1.1⁵ ≈ 1.61 → 年均增长 **10%**

---

### 7. 比重

```
比重 = 部分量 ÷ 整体量
```

**例**：某地第三产业增加值 2400 亿元，GDP 6000 亿元。
比重 = 2400 ÷ 6000 = **40%**

---

### 8. 比重的变化

```
判断升降：部分增长率 a 与整体增长率 b 比较
  a > b → 比重上升
  a < b → 比重下降
  a = b → 比重不变

变化幅度（百分点）≈ 现期比重 × (a − b) ÷ (1 + a)
```

**例**：2026 年某行业中民营企业占比 60%，行业整体增长 10%，民营企业增长 15%。
a(15%) > b(10%) → 比重上升；
变化幅度 = 60% × (15% − 10%) ÷ 1.15 ≈ **2.6 个百分点**，即升至约 62.6%

> 💡 问"上升/下降几个百分点"答具体数值；只问"上升还是下降"就只答方向。

---

### 9. 平均数

```
平均数 = 总量 ÷ 份数
```

**例**：某年粮食总产量 6000 万吨，播种面积 1000 万公顷。
单产 = 6000 ÷ 1000 = **6 吨/公顷**

---

### 10. 平均数的增长率

```
平均数增长率 = (a − b) ÷ (1 + b)
```

**例**：某公司总收入增长 12%，员工人数增长 5%，则人均创收增长：
(12% − 5%) ÷ 1.05 ≈ **6.7%**

---

### 11. 倍数

```
是几倍 = A ÷ B
多几倍 = A ÷ B − 1
```

**例**：A 为 300，B 为 100 —— A 是 B 的 **3 倍**，A 比 B **多 2 倍**

> 💡 "是几倍"和"多几倍"差 1，这是最高频的选项陷阱。

---

### 12. 贡献率

```
贡献率 = 部分增长量 ÷ 整体增长量
```

**例**：某地 GDP 增长 500 亿元，其中工业增长 150 亿元。
工业贡献率 = 150 ÷ 500 = **30%**

---

### 13. 拉动增长率

```
拉动增长率 = 部分增长量 ÷ 整体基期量
```

**例**：某市 GDP 基期 1000 亿元，其中旅游业增长 150 亿元。
旅游业拉动 GDP 增长 = 150 ÷ 1000 = **15 个百分点**

---

### 14. 混合增长率

```
整体增长率介于两部分增长率之间，且偏向基期量较大的一方
（精算可用十字交叉）
```

**例**：甲部分基期 300 亿元、增长 10%；乙部分基期 100 亿元、增长 30%。
整体增长量 = 30 + 30 = 60，整体基期 400 → 整体增长 **15%**
15% 介于 10%~30%，且更靠近 10%，因为甲基期更大。

---

### 15. 单位换算

```
1 亿 = 10000 万
1 万亿 = 10000 亿
```

**例**：12.5 万件 = 0.00125 亿件；问"多少万件"时不要把亿直接抄上去

---

## 二、速算技巧

| 技巧 | 用法 | 例子 |
|------|------|------|
| **截位直除** | 分母保留 3~4 位，选项差距大时只留 2 位 | 23456 ÷ 789 ≈ 23500 ÷ 790 ≈ **29.7** |
| **化除为乘** | 1 ÷ (1+r) ≈ 1 − r + r²（r 小时够用） | 448 ÷ 1.12 ≈ 448 × 0.893 ≈ **400** |
| **特征分数** | 把百分数换成 1/n 再约分 | 现期 900、增长 12.5% → 增长量 = 900 × (1/8) ÷ (9/8) = 900 ÷ 9 = **100** |
| **首数法** | 选项首位不同时只算第一位 | 7860 ÷ 3.14，首数约 2500，直接选首位为 2 的选项 |
| **尾数法** | 加减法看末位 | 3421 + 2587 + 1183，末位 1+7+3 = 11 → 尾数 1 |
| **有效数字** | 乘除保留 2~3 位有效数字 | 8.73 × 1.42 ≈ 8.7 × 1.4 ≈ **12.2** |

## 三、必背坑点清单

| 陷阱 | 说明 | 例子 |
|------|------|------|
| **同比 vs 环比** | 同比是去年同期，环比是上一统计期 | "环比增长 3%" 可能只是比上个月 |
| **百分数 vs 百分点** | 增长率用百分数，比重的升降用百分点 | 占比从 40% 到 42%，是"提高 2 个百分点"，不是"增长 2%" |
| **增长率 vs 增长量** | 看单位：带 % 是增长率，带具体量是增长量 | 题干问"增长了多少亿元"→ 求增长量 |
| **时间区间** | 1—11 月、全年、累计、当月不可混用 | 材料给"1—11 月"，问全年必须另外找数 |
| **范围** | 全国 vs 某省、"其中"是子集、表格合计行 | "其中"后面是整体的一部分，不能和整体相加 |
| **单位量级** | 万 / 亿、吨 / 万吨、美元 / 人民币 | 12.5 万件写成 12.5 亿件直接错 |
| **倍数问法** | "是几倍"与"多几倍" | 3 倍 ≠ 多 3 倍（多 3 倍是 4 倍关系） |
| **文字表述** | "超过""约""不足""翻番" | 翻一番 = 变为 2 倍，翻两番 = 变为 4 倍 |

## 四、做题流程

| 步骤 | 要点 |
|------|------|
| **1. 先看题干** | 判断考增长率、比重还是平均数，再回材料找数 |
| **2. 定位数据** | 按时间、地区、指标三项对齐，防止看错行 |
| **3. 列式不硬算** | 先化简（分数、约分），再决定用哪种速算 |
| **4. 看选项定精度** | 选项差距大就粗算，差距小才截 3~4 位 |
| **5. 综合分析题最后做** | 四个选项逐个排除，常从"最不可能"的选项入手 |
