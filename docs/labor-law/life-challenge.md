# 人生挑战清单

> 人生不是被动度过，而是主动设计。以下按**语言、文字、AI、运动、社交**五大模块，列出值得挑战的目标清单。每个模块分「入门 → 进阶 → 硬核」三档，按自身阶段取用。

---

## 一、语言（外语能力）

语言是打开世界的第一把钥匙——**每掌握一门语言，就多一个人生副本**。

| 阶段 | 挑战目标 | 达成标志 |
|:---|:---|:---|
| **入门** | 英语重新捡起来：背完 3500 高频词 | 不查词典能读懂 BBC / VOA 慢速英语 80% |
| **入门** | 养成每日 30 分钟英语输入习惯 | 连续坚持 100 天（播客 / 油管 / 美剧）|
| **进阶** | 雅思 6.5 / 托福 90 / 六级 550+ | 拿到成绩单，具备留学/外企门槛 |
| **进阶** | 用英语做一次 10 分钟演讲/工作汇报 | 不背稿、能即兴回答提问 |
| **进阶** | 看剧不看字幕 | 一部美剧（如《老友记》《办公室》）裸听懂 90% |
| **硬核** | 雅思 8 / 托福 110 / CATTI 二级笔译 | 达到专业翻译或同传准入水平 |
| **硬核** | 掌握第二外语（日 / 韩 / 法 / 德 / 西 选一）| 达到日常会话 + 阅读原文新闻水平（如日语 N2）|
| **硬核** | 用外语写一本书 / 做一个全英文自媒体账号 | 形成可对外交付的作品 |

## 二、文字（写作表达）

写作是最低成本的复利——**会写的人，永远比不会写的人多一个杠杆**。

| 阶段 | 挑战目标 | 达成标志 |
|:---|:---|:---|
| **入门** | 每天写 500 字日记 / 复盘 | 连续坚持 365 天 |
| **入门** | 建立自己的写作 SOP（选题→大纲→初稿→修改）| 写 10 篇结构完整的文章 |
| **进阶** | 公众号 / 知乎 / 小红书 / 博客坚持更新 1 年 | 产出 ≥ 50 篇，粉丝 ≥ 1000 |
| **进阶** | 写一篇 1 万字以上的深度长文 | 被一个平台首页推荐 / 大 V 转发 |
| **进阶** | 投稿并被杂志 / 媒体 / 出版社录用 | 拿到第一笔稿费 |
| **硬核** | 出版一本实体书（自出版也算）| ISBN 书号 + 上架销售 |
| **硬核** | 写一个连载小说 / 专栏（≥ 20 万字）| 完本，并有固定读者群 |
| **硬核** | 用文字年入 10 万+（专栏 / 课程 / 咨询 / 出书）| 文字成为第二收入曲线 |

## 三、AI（人工智能）

AI 是这个时代最大的杠杆——**不会用 AI 的人将被会用 AI 的人替代**。

| 阶段 | 挑战目标 | 达成标志 |
|:---|:---|:---|
| **入门** | 熟练使用 3 款以上 AI 工具（ChatGPT / Claude / Gemini / 文心 / Kimi 等）| 日常 50% 的搜索和写作交给 AI 完成 |
| **入门** | 掌握 Prompt 工程基本功 | 能用结构化提示词解决真实工作问题（角色 / 任务 / 约束 / 示例）|
| **进阶** | 用 AI 编程做出一个完整小工具 | 上线并解决自己或身边人的一个痛点（爬虫 / 报表 / 自动化脚本）|
| **进阶** | 搭建一个 AI 工作流（如 Coze / Dify / n8n / LangChain）| 跑通「输入 → AI 处理 → 自动输出」闭环 |
| **进阶** | 学会微调 / RAG / Agent 中至少一项 | 训出或部署一个属于自己数据的小模型 / 知识库助手 |
| **硬核** | 用 AI 做产品 / 副业并产生收入 | AI 相关月收入 ≥ 1 万（代做 / 咨询 / SaaS / 课程）|
| **硬核** | 独立做出一个 AI 应用并上架（App / 小程序 / 网站）| 真实用户 ≥ 1000，或付费用户 ≥ 100 |
| **硬核** | 发表 AI 相关论文 / 开源项目 Star ≥ 1000 | 进入行业影响力圈层 |

## 四、运动（身体管理）

身体是所有挑战的底盘——**30 岁后，身材就是实力的外显**。

| 阶段 | 挑战目标 | 达成标志 |
|:---|:---|:---|
| **入门** | 体脂率降到健康区间（男 < 20%，女 < 25%）| 体测报告 / 体脂秤数据 |
| **入门** | 养成每周运动 3 次习惯 | 连续坚持 100 天，体重稳定 |
| **进阶** | 完成一次半程马拉松（21.0975 km）| 拿到官方完赛奖牌 |
| **进阶** | 标准引体向上 10 个 / 俯卧撑 50 个 / 深蹲自重 1 倍 | 力量达标 |
| **进阶** | 学会一项新运动（游泳 / 网球 / 攀岩 / 拳击 / 滑雪 任一）| 能独立完成基础动作并享受过程 |
| **硬核** | 完成全程马拉松（42.195 km）| 拿到官方完赛奖牌 |
| **硬核** | 练出肉眼可见的腹肌 / 人鱼线 | 体脂男 < 12%，女 < 18%，并保持半年 |
| **硬核** | 挑战越野跑 / 铁人三项 / 斯巴达勇士赛 | 完赛任意一项 |
| **硬核** | 取得健身教练 / 瑜伽教练 / 潜水 / 滑雪教练证 | 证书 + 可副业变现 |

## 五、社交（人际连接）

社交是隐形资产——**你认识谁，决定了你能走多远**。

| 阶段 | 挑战目标 | 达成标志 |
|:---|:---|:---|
| **入门** | 每周主动联系 1 位老朋友 / 前辈 | 坚持 1 年，重建 50+ 弱连接 |
| **入门** | 克服社交恐惧：单独参加 3 次陌生人聚会 / 活动 | 能自如自我介绍 1 分钟 |
| **进阶** | 认识 100 位新朋友（不同行业 / 背景）| 名单 + 备注 + 至少 3 次深聊 |
| **进阶** | 做一次 30 人以上的公开分享 / 演讲 | 完整呈现并获得现场反馈 |
| **进阶** | 主动链接 3 位你钦佩的行业前辈 | 约到一对一咖啡 / 电话深聊 |
| **硬核** | 组织一场 50 人以上的线下活动 / 沙龙 | 独立完成策划、招募、主持 |
| **硬核** | 建立一个高质量的付费社群（≥ 100 人）| 社群年营收 ≥ 5 万 |
| **硬核** | 成为某个圈子的「连接器」 | 别人想到某个领域时第一个想到你 |
| **硬核** | 一年做 12 次一对一免费咨询 / 帮助陌生人 | 建立长期影响力与口碑 |

## 六、通关建议

| 原则 | 说明 |
|:---|:---|
| **不要五线全开** | 同一时期最多主攻 2 个模块，其他保持「最低维持」即可 |
| **先入门后硬核** | 任何模块先完成入门档，建立正反馈，再冲硬核 |
| **公开承诺** | 把目标发朋友圈 / 社群 / 记账本，外部监督提高完成率 |
| **以年为单位** | 人生挑战不看单日表现，看一年下来你走了多远 |
| **定期复盘** | 每月末花 30 分钟对照清单，勾掉已完成、调整下一阶段 |

> 💡 **一句话总结**：语言打开世界，文字撬动杠杆，AI 放大效率，运动撑起底盘，社交连接机会——五线并进，人生指数级升级。
