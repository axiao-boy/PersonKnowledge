## 证监会和交易所

中国证券监督管理委员会（**证监会/CSRC**）是负责中国证券市场监管的国家机构。

- 主要关注企业披露信息
- 年报、季报为定期报告，除此之外还有临时报告

交易所分为证券交易所（北上深）和期货交易所。

补充：银行间市场，这个业务很小众，但我工作确实接触过...

### 交易制度

- **证券**：普通股票为 T+1，部分 ETF 和可转债为 T+0。
- **期货**：所有品种均为 T+0。

## 新股申购

### 什么是新股申购？

**新股申购**是指投资者在公司首次公开发行股票（IPO）时，按照发行价购买新股票的行为。中签后可以在上市首日卖出获利。

### 申购条件

| 条件 | 要求 |
|------|------|
| **账户要求** | 持有沪深交易所的股票账户 |
| **市值要求** | T-2日前20个交易日日均市值不低于1万元（沪市/深市分开计算） |
| **板块权限** | 申购对应板块新股需开通该板块权限（如科创板、创业板） |

### 申购规则总结

| 项目 | 内容 |
|------|------|
| **市值计算（沪市）** | 每1万元市值可申购1个单位（1000股） |
| **市值计算（深市）** | 每5000元市值可申购1个单位（500股） |
| **市值合并** | 同一投资者多个账户市值合并计算，只能用一个账户申购 |
| **申购流程** | T日申购 → T+1日配号 → T+2日中签结果（16:00前缴款）→ T+3日资金解冻/股票入账 |
| **申购特点** | 无需预缴款，中签后再缴纳；委托不可撤销；同一新股只能申购一次 |

### 各板块申购规则对比

| 板块 | 申购单位 | 市值门槛 | 缴款方式 | 备注 |
|------|----------|----------|----------|------|

| **创业板** | 500股/单位 | 1万元市值 | T+2日缴款 | 需开通创业板权限 |

| **北交所** | 100股/单位 | 100股对应市值 | 申购时全额缴款 | 需开通北交所权限 |

## 美元

### 购汇额度

| 项目 | 限额 |
|------|------|
| **年度购汇限额** | 等值5万美元（所有外币共用此额度） |
| **年度结汇限额** | 等值5万美元（所有外币共用此额度） |
| **超过限额** | 需提供用途证明材料 |

**注意**：欧元、英镑、日元等所有外币共用同一个年度5万美元购汇限额，不是每种货币单独5万美元。例如：
- 购买3万美元的美元后，还能购买等值2万美元的欧元或其他货币
- 购买等值5万美元的欧元后，当年将无法再购买其他外币
