# 健身指南

## 健身核心原则

1. **热量缺口是第一要务**：不管增重还是减重，热量控制是核心
2. **有氧运动**：减脂、提升耐力
3. **无氧运动**：增肌、提高代谢、塑形

## 训练公式

```
无氧 + 有氧 + 充足蛋白质 + 水 + 充分休息
```

## 体重记录

| 频率 | 时间 | 要点 |
|------|------|------|
| **每日** | 早起空腹 | 称体重记录 |
| **每周** | 汇总 | 以周为单位观察变化趋势 |

> 💡 单日体重波动正常，关注周/月趋势才有意义。

## 无氧力量训练部位

| 部位 | 说明 |
|------|------|
| **胸** | 卧推、俯卧撑等 |
| **背** | 引体向上、划船等 |
| **核心** | 平板支撑、卷腹等 |
| **腿** | 深蹲、弓步等 |

## 有氧运动推荐

| 类型 | 适合人群 | 特点 |
|------|----------|------|
| **快走**（推荐） | 所有人 | 低冲击、易坚持、适合日常 |
| **高强度有氧** | 有一定基础 | 效率高、燃脂快 |

### 训练分段

| 时间点 | 训练内容 |
|--------|----------|
| 0:10 | 上半身热身 |
| 7:48 | 下半身耐力 |
| 18:31 | 力量 |
| 28:39 | 核心 |

这个训练的强度对于降低体重正常减脂绰绰有余

### 训练建议

> 💡 **新手建议**：先拆分为多组单项目训练，等身体变强后再考虑全套一组完成。

如果训练过程中存在无氧力量训练就不要太关注体重，因为肌肉密度比脂肪高，所以体重会增加。
坚持保持热量缺口继续训练即可。


## 心得

1.可以不吃早餐，但午餐和晚餐要规律，水一定要多喝。
2.保持低压充足睡眠
3.蛋白质摄入尽可能多，其次训练
