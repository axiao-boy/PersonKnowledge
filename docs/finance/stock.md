
## 股票（以下均以国内市场举例）

### 股票开户

交易所交易->证券公司开户（证券公司交易管理），资金由银行独立保管

注意要点：**佣金收费协议书**--->规定交易佣金费率
app直接开户的费率一般最高，联系客户经理能否优惠
**新开立的A股账户统一实行“T日开户、T+1交易日**


交易成本=佣金+印花税+过户费

（买卖双向收取）单笔交易佣金 = 成交金额 × 佣金费率 （1.5%-3%，单笔交易佣金设有最低门槛，如A股5元）
(仅卖出时单边收取)印花税 = 卖出成交金额 × 0.05%（印花税率）
(买卖双向收取)过户费 = 成交金额 × 0.01‰（过户费率）

### 股票如何上市

企业请保荐机构（券商）做担保，会计事务所，律师事务所，资产评估机构等中介机构做审计，内控合规，法律文件，资产评估

证监局备案验收----->证券交易所审核----->证监会注册批文----->首次公开募股（IPO）,资金到位后挂牌正式交易

重点关注文件：
**招股意向书**（全面披露公司信息）
**发行公告**（主要说明本次发行的具体操作规则和时间节点）
**路演**（推介公司，解答疑问）

#### 新股申购（打新）
《发行公告》显示的具体T日日期时间可参与，注意新股申购有门槛，主要是交易权限，资金，交易经验

| 板块 | 申购/开通条件 |
|------|--------------|
| **沪深主板** | 申购日（T日）前20个交易日，日均持有对应市场（沪市或深市）非限售A股股份市值 ≥ 1万元 |
| **申购额度换算** | 每5000元市值可申购500股，不足5000元的部分不计入申购额度 |
| **创业板**（300开头） | 开通前20个交易日日均资产 ≥ 10万元 + 具备24个月（2年）以上证券交易经验 |
| **科创板**（688开头） | 开通前20个交易日日均资产 ≥ 50万元 + 具备24个月（2年）以上证券交易经验 + 风险测评等级 ≥ C4 |
| **北交所**（8/920开头） | 开通前20个交易日日均资产 ≥ 50万元 + 具备24个月（2年）以上证券交易经验 + 风险测评等级 ≥ C4（已开通科创板权限可一键豁免） |


### 交易规则
| 时段 | 交易规则 |
|------|----------|
| 全天 | **T+1 交易**（当日买入，次日方可卖出）|
| 9:15 - 9:20 | 可挂单，也可撤单 |
| 9:20 - 9:25 | 只能挂单，不能撤单 |
| 9:30 - 11:30 | 实时连续竞价成交，**价格优先，时间优先，逐笔成交** |
| 11:30 - 13:00 | 休市，但可挂单、撤单 |
| 13:00 - 14:57 | 实时连续竞价成交 |
| 14:57 - 15:00 | 只能挂单，无法撤单（尾盘集合竞价阶段）|
| 15:05 - 15:30 | 收盘后，系统按「时间优先」原则，以当日「收盘价」为统一成交价 |

## 基金
众人凑钱，交由基金公司打理操盘，商业银行保管资金

**指数基金，板块基金**

### 基金开户

成本=申购费/认购费（买入时收取）+赎回费（卖出时收取）+管理费（支付给基金公司）+托管费（支付给托管银行）


#### 场内基金和场外基金

**「场」指证券交易所**。场内 = 在交易所像股票一样买卖；场外 = 不在交易所，通过基金公司/银行/第三方平台申购赎回。

##### 核心对比表

| 对比维度 | 场内基金 | 场外基金 |
|---------|---------|---------|
| **交易场所** | 证券交易所（上交所/深交所） | 基金公司、银行、第三方平台（支付宝/天天基金/且慢）|
| **交易账户** | 证券账户（券商APP） | 基金账户（基金公司/银行/平台APP）|
| **交易方式** | 买入/卖出（和股票一样挂单） | 申购/赎回（提交给基金公司）|
| **成交价格** | **实时市价**（盘中随行就市，9:30-15:00）| **当日收盘净值**（T日15:00前提交按当日净值）|
| **成交速度** | T+1 日交收（当天买入次日可卖）| T+1 确认份额，赎回资金到账 T+2~T+7 |
| **交易费用** | **佣金**（同股票，万1~万3，单笔最低5元），**无申购赎回费** | 申购费（0.1%~1.5%）+ 赎回费（0~1.5%，持有越久越低）+ 管理费 + 托管费 |
| **起购门槛** | 100 份起（1手，几十到几百元）| **1 元甚至 1 分起**（门槛极低）|
| **定投支持** | ⚠️ 部分券商支持，不如场外灵活 | ✅ 自动定投做得最好，支持智能定投 |
| **资金门槛** | 需先开通股票账户 | 有身份证+银行卡即可 |
| **价格波动** | 盘中实时跳动，可做波段 | 每天只有一个净值，适合长期持有 |
| **类型主流** | ETF、LOF、封闭式基金 | 普通开放式基金、货币基金、QDII |
