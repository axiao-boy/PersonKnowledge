# 申论素材积累

> 素材不是名言警句库，而是一套"问题—原因—对策—表述"的现成表达。按大类攒，一材多用。

## 素材卡片结构

每条素材按一个固定格式记，缺任何一项都别记：

| 栏目 | 写什么 |
|------|--------|
| **问题** | 这个主题最常见的痛点（2~3 条） |
| **原因** | 为什么会这样（部门协同、资金、观念、机制） |
| **对策** | 能直接写进答案的措施表述 |
| **表述** | 官方原话或金句，可作段首观点句 |
| **案例** | 一个具体做法（最好带数据、最好是本省的） |

## 一、基层治理与乡村振兴

| 栏目 | 内容 |
|------|------|
| **问题** | 村级组织"牌子多、报表多"，干部疲于应付；群众参与度低，"干部干、群众看"；农村空心化、人才外流 |
| **原因** | 考核层层加码；权责不匹配；缺乏激励机制；公共服务向城镇集中 |
| **对策** | 网格化管理、减负清单与事项准入制度、自治法治德治"三治融合"、积分制、村规民约、产业联农带农、人才回引 |
| **表述** | "基层强则国家强，基层安则天下安"；"治理有效是乡村振兴的重要基石" |
| **案例** | 湖北"美好环境与幸福生活共同缔造"——群众共谋、共建、共管、共评、共享；强县工程推动资源下沉 |

**用法**：B 卷（县乡）高频。对策题按"组织＋群众＋资源＋机制"分层写；公文题常考倡议书、工作方案。

## 二、经济发展与营商环境

| 栏目 | 内容 |
|------|------|
| **问题** | 审批环节多、隐性门槛多、政策兑现慢；融资难融资贵；民间投资信心不足 |
| **原因** | 部门协同不足；考核重"招引"轻"服务"；法治保障和信用体系不健全 |
| **对策** | 一网通办、一件事一次办、清单管理、容缺受理、免申即享、无事不扰有呼必应、公平竞争审查、政企常态化沟通 |
| **表述** | "以市场主体感受为第一标准"；"营商环境就是生产力、竞争力" |
| **案例** | 光谷产业链招商；"高效办成一件事"改革推动审批时限大幅压缩 |

**用法**：A 卷常与"高质量发展"合并出题。作文分论点可用"放管服—法治保障—信用体系"三层。

## 三、科技创新与数字经济

| 栏目 | 内容 |
|------|------|
| **问题** | 科技成果转化率低、中小企业数字化能力弱、数据壁垒、结构性人才短缺 |
| **原因** | 产学研脱节；中试与场景不足；数据确权与共享规则缺失；人才评价机制僵化 |
| **对策** | 产学研协同、中试平台、揭榜挂帅、数字化转型补贴、数据要素市场化、公共场景开放、人才"引育留用" |
| **表述** | "科技创新是引领发展的第一动力"；"以新质生产力塑造发展新优势" |
| **案例** | 光谷科技创新大走廊；人工智能与制造业融合改造传统产线 |

**用法**：适合 A 卷综合分析题与作文；B 卷可写"数字乡村""电商助农"。

## 四、生态文明与绿色发展

| 栏目 | 内容 |
|------|------|
| **问题** | 污染治理易反弹、生态补偿机制不健全、保护与发展的矛盾、农村人居环境短板 |
| **原因** | 考核导向偏差；跨区域协同不足；生态产品价值实现路径不清；群众参与不够 |
| **对策** | 河湖长制、林长制、生态补偿与转移支付、绿色低碳转型、长江大保护、十年禁渔、农村垃圾污水治理 |
| **表述** | "绿水青山就是金山银山"；"共抓大保护、不搞大开发" |
| **案例** | 湖北"千湖之省"的湖泊治理；丹江口库区作为南水北调中线水源地的保护实践 |

**用法**：湖北几乎是必考背景。对策题按"制度—技术—市场—群众"四维展开。

## 五、民生保障与社会服务

| 栏目 | 内容 |
|------|------|
| **问题** | 就业结构性矛盾、养老托育供给不足、看病难看病贵、教育资源配置不均、老旧小区配套缺失 |
| **原因** | 供给结构失衡；基层服务能力弱；社会力量参与不足；保障标准与财力不匹配 |
| **对策** | 就业优先与技能培训、社区嵌入式养老、普惠托育、医保集采、老旧小区改造、15 分钟生活圈、"一老一小"整体解决方案 |
| **表述** | "民生是最大的政治"；"让群众在家门口享有优质服务" |
| **案例** | 社区食堂与老年助餐点；嵌入式养老服务中心进社区 |

**用法**：最贴近群众生活，B 卷和公文题（建议、方案）常用；作文易写成"小切口大主题"。

## 六、文化自信与文旅融合

| 栏目 | 内容 |
|------|------|
| **问题** | 传统文化保护与利用不足、文旅产品同质化、公共文化服务城乡不均 |
| **原因** | 保护让位于开发；创意与人才不足；设施运营维护缺位 |
| **对策** | 非遗活化利用、文化 IP 打造、公共文化设施免费开放、文旅融合、"夜经济"与新场景 |
| **表述** | "文化自信是更基本、更深沉、更持久的力量" |
| **案例** | 荆楚文化、编钟乐舞、长江国家文化公园建设；黄鹤楼、武当山的文旅开发 |

**用法**：作文易出彩，注意别写成"讲故事"，要落到"机制＋供给＋传播"。

## 七、政府自身建设

| 栏目 | 内容 |
|------|------|
| **问题** | 形式主义官僚主义、层层加码、责任悬空、数据注水、政策"一刀切" |
| **原因** | 考核指标不合理；问责与容错失衡；监督渠道不畅；干部能力不足 |
| **对策** | 精简文件会议、考核清单化、督查检查瘦身、容错纠错机制、政务公开、依法行政、信用监管、"吹哨报到" |
| **表述** | "为基层减负要减到实处"；"把制度优势转化为治理效能" |
| **案例** | 政务热线"一号响应"；审批事项"一窗受理、集成服务" |

**用法**：几乎每个题目都能用一层——写对策时补"健全考核、压实责任、强化监督"。

## 使用方法

### 1. 一材多用

同一条素材挂多个标签，避免重复积累：

| 素材 | 可套用的主题 |
|------|-------------|
| 共同缔造 | 基层治理、乡村振兴、群众参与、公共服务 |
| 光谷科技创新大走廊 | 科技创新、人才、产业升级、区域发展 |
| 社区嵌入式养老 | 民生保障、基层治理、公共服务供给 |
| 河湖长制 | 生态文明、责任机制、制度创新 |

### 2. 素材只占答案的 20%

主体仍是材料要点，素材用来"换词"和"补例"：

- 材料写"村民不愿意参与"，你写"群众主体作用发挥不充分"
- 材料写"检查太多"，你写"考核事项层层加码，基层负担重"

### 3. 三段常用表述模板

```
开头：近年来，××工作取得明显成效，但仍存在××、××等问题，
      与群众期盼还有差距。
分论点：一是健全××机制。建立××制度，明确××责任，
      推动××落地见效。
结尾：××非一日之功，需要久久为功、持续发力，
      以钉钉子精神把各项举措落到实处。
```

### 4. 每个大类准备 1 个湖北案例

A 卷体现理论素养，B 卷体现"懂本地"，本地案例比外地案例更稳。

## 积累节奏

| 周期 | 动作 |
|------|------|
| **每天** | 精读 1 篇评论（人民日报评论、湖北日报评论），划出观点句、对策句 |
| **每周** | 按大整理 5~8 张卡片，同类合并，删掉空泛的 |
| **每两周** | 挑 1 个大类写 300 字短评，检验素材能否落笔 |
| **考前** | 只翻卡片，读对策表述和案例，不再看新素材 |

## 来源渠道

| 用途 | 渠道 |
|------|------|
| 观点与论证 | 人民日报评论、求是、光明日报、经济日报 |
| 对策表述 | 中央一号文件、政府工作报告、省市"十四五"规划 |
| 本地案例 | 湖北省政府工作报告、湖北日报、各市州政府工作报告 |
| 数据 | 国家统计局、湖北省统计局 |
| 基层视角 | 半月谈、新华社评论 |
