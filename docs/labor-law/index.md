# 劳动法律知识要点

《劳动法》
《劳动合同法》

## 📋 证据收集清单

### 必备证据

1. **劳动合同原件**、工资银行流水、社保缴纳记录、工作证/工卡/工牌、offer
2. **工资条**（每月）/薪资明细、考勤打卡记录、加班调休记录
3. **聊天记录**、公司通知书、工作邮件
4. **离职/辞退通知书**、沟通录音、EMS邮寄《解除劳动合同通知书》

## 🔑 核心术语

- **用人单位**：雇佣劳动者的企业、事业单位、个体经济组织等
- **劳动者**：与用人单位建立劳动关系的自然人
- **劳动合同**：劳动者与用人单位确立劳动关系、明确双方权利和义务的协议
- **工会**：职工自愿结合的工人阶级群众组织
- **职工代表大会**：企业实行民主管理的基本形式
- **集体合同**：工会代表职工与用人单位签订的书面协议
- **劳务派遣**：劳务派遣单位派遣劳动者到用工单位工作
- **非全日制用工**：以小时计酬为主的用工形式

## 1️⃣ 试用期时间问题

- **劳动合同期限三个月以上不满一年的**：试用期不得超过一个月
- **一年以上不满三年的**：试用期不得超过二个月
- **三年以上固定期限和无固定期限的**：试用期不得超过六个月

> **注意**：同一单位只能约定一次试用期。

> **赔偿预估**：违法约定试用期的，以正式工资标准补发超出试用期部分的工资差额。例如：劳动合同1年，试用期约定3个月（违法，最多2个月），第3个月按试用期工资8000元发放，正式工资10000元，则可要求补发2000元。

---

## 2️⃣ 试用期工资问题

劳动者在试用期的工资不得低于本单位相同岗位最低档工资或者劳动合同约定工资的**百分之八十**，并不得低于用人单位所在地的最低工资标准。

> **补充**：约定工资是税前工资，即劳动合同上写明的工资数额。

> **赔偿预估**：试用期工资低于约定工资80%或最低工资标准的，可要求补发差额。例如：约定工资10000元，试用期工资仅发7000元（低于8000元），则每月可要求补发1000元。

---

## 3️⃣ 试用期不签合同或者不缴社保

- **建立劳动关系应当订立书面劳动合同**，最迟应在用工之日起一个月内订立
- **《社会保险法》第五十八条规定**：用人单位应当自用工之日起三十日内为其职工申请办理社会保险登记

> **要点**：牢记一个月必须签合同、必须缴社保，劳动关系从用工当天开始确立。

> **赔偿预估**：①未签合同：自第2个月起至补签合同前每月支付双倍工资，最多11个月。例如：入职4个月未签合同，可要求额外支付3个月工资。②未缴社保：可要求补缴，若因未缴社保导致损失（如无法报销医疗费用），可要求赔偿实际损失。

---

## 4️⃣ 试用期被辞退

若被辞退，要求公司出具：

- 书面的录用条件
- 考核标准
- 不合格的具体证据

> **要点**：试用期辞退必须说明理由。

> **赔偿预估**：若公司无法证明不符合录用条件而违法辞退，可要求支付赔偿金（2N）。例如：工作3个月被违法辞退，月工资10000元，可要求支付10000元（0.5×2=1个月工资）。若公司未提前通知，还可额外要求支付1个月代通知金（N+1）。

## 5️⃣ 劳动合同上必须包含的内容

### 基本信息

- **用人单位基本信息**：名称、住所、法定代表人或主要负责人
- **劳动者基本信息**：姓名、住址、身份证号码

### 合同条款

- **劳动合同期限**：固定期限、无固定期限、以完成一定工作任务为期限
- **工作内容和工作地点**：具体工作岗位、职责范围、工作场所
- **工作时间和休息休假**：工时制度、休息安排、法定假期
- **劳动报酬**：工资数额（或构成）、发放方式、支付时间
- **社会保险**：用人单位依法缴纳各项社会保险
- **劳动保护、劳动条件和职业危害防护**：保障工作安全与健康

> **社保注意**：有些公司会协商"自愿按照某个标准如基本工资来缴纳社保"，这可能存在问题。

> **赔偿预估**：①合同缺少必备条款：劳动行政部门责令改正；造成损害的，承担赔偿责任。②未依法缴纳社保：可要求补缴，因未缴社保导致无法享受待遇的，可要求赔偿实际损失。③工资标准未明确：可参照同岗位工资或集体合同标准，不足部分可要求补发。

## 6️⃣ 拖欠工资

**构成违法的情形**：

- 超过劳动合同约定的发薪日
- 超过一个月（30天）未支付

即使公司经营困难，若未征得工会或职工代表同意，延期超过30天也属违法。

> **赔偿预估**：拖欠工资的，劳动行政部门责令限期支付；逾期不支付的，责令用人单位按应付金额50%以上100%以下的标准向劳动者加付赔偿金。例如：拖欠工资5000元超过30天，可要求支付5000元 + 2500~5000元赔偿金。

## 7️⃣ 解除或者终止合同

### 补偿标准

| 情形 | 补偿金额 |
|------|----------|
| 员工主动辞职 / 严重违纪被开除 | 0 补偿 |
| 单位合法解除 / 终止劳动合同 | N |
| 单位合法辞退（《劳动合同法》第40条）+ 未提前30天通知 | N+1 |
| 单位无合法理由、程序违法辞退 | 2N |

### 经济补偿金（N）计算

- 每满1年支付1个月工资
- 满6个月不满1年的，按1年计算
- 不满6个月的，支付半个月工资

### 操作要点

1. **要求公司出具盖章的《解除/终止劳动合同通知书》**
2. **不乱签《离职交接表》或《自愿离职协议》**
3. **劳动仲裁时效为1年**
4. **务必在离职申请中写明真实原因**（如"因公司未依法缴纳社保被迫离职"），切勿写"个人原因"

> **赔偿预估**：①加班费差额：工作日150%、休息日200%、法定节假日300%。例如：月工资10000元，月加班30小时（周末），可要求补发约3448元加班费。②未休带薪年假：按日工资收入300%支付。例如：5天未休年假，日工资460元，可要求支付6900元。③高温补贴：各地标准不同，约每月100-300元，未发放可要求补发。

## 8️⃣ 不续签合同

- **默认情况**：不续签可拿 N
- **新合同低于旧合同待遇不续签**：也可以拿到 N
- **连续两次固定期限合同后不续签**（正常应续签无固定期限劳动合同）：可以拿 2N

> **赔偿预估**：①工作3年，月工资10000元，公司不续签：可拿30000元（N=3）。②新合同工资降至8000元，员工拒绝续签：可拿30000元（N=3）。③连续两次固定期限合同后公司拒签无固定期限合同：可拿60000元（2N=6）。

## 9️⃣ 用人单位名称发生变更重新签订劳动合同

### 需要注意的权益

- **工龄连续计算**：单位名称变更不影响工龄连续计算，新单位需承认原单位工作年限
- **原合同权利义务继承**：变更后的单位需继承原劳动合同的全部权利义务（工资、社保、福利等）
- **书面确认变更**：要求单位出具名称变更证明，并在新合同中注明"承继原劳动合同"
- **经济补偿年限**：若后续解除合同，经济补偿按累计工龄计算（原单位+新单位年限）
- **社保关系延续**：社保缴费年限连续计算，无需重新开户

### 操作要点

1. **拒绝重新签订**：若单位要求重新签订且变更关键条款（降薪、降职、缩短工龄），有权拒绝
2. **保留证据**：保存原合同、名称变更通知、工作证明等材料
3. **书面声明**：在新合同中注明"工龄自XXXX年XX月XX日起连续计算"

> **赔偿预估**：①若单位以名称变更为由要求重新签订并变相解除原合同：可要求支付经济补偿金N（按累计工龄）。②若单位强制降薪降职：可要求补发工资差额，并以"未按约定提供劳动条件"为由被迫离职，要求N赔偿。③若单位拒绝承认原工龄：可要求按原工龄支付经济补偿（工作5年，月工资10000元→50000元）。④未签新合同超过1个月：自第2个月起支付双倍工资（最多11个月）。

## 🔟 只签电子合同的场景

### 法律效力

- **合法有效**：电子劳动合同与书面劳动合同具有同等法律效力（《电子签名法》）
- **生效要件**：需具备可靠电子签名、合同内容可随时调取查用、数据电文完整保存

### 有效电子合同的要件

1. **身份认证**：双方身份真实可验证（实名认证）
2. **意愿表达**：电子签名是签署人真实意愿表示
3. **不可篡改**：合同内容和签名可防篡改
4. **完整保存**：合同数据完整、可随时查阅

### 需要注意的权益

- **保存原始文件**：下载并保存电子合同原始PDF或完整数据文件
- **验证电子签名**：确认签名方身份和签名时间戳
- **索要书面副本**：有权要求单位提供纸质合同副本
- **防止单方面修改**：定期备份合同内容，防止单位后台篡改
- **注意合同期限**：电子合同到期前主动确认续签

> **赔偿预估**：①电子合同不具备法律效力（无可靠签名、内容可篡改）：视同未签书面合同，自第2个月起支付双倍工资（最多11个月）。②单位单方面篡改电子合同内容：可要求按原合同履行，造成损失的要求赔偿。③拒绝提供纸质副本且电子合同无法验证：可主张合同无效，要求重新签订并支付双倍工资。④因电子合同证据不足导致维权失败：可要求单位承担举证不利后果。

## 社保和公积金

理论上社保和公积金在大于最低基数前提下都得按照全额税前工资为基数缴纳，社保缴纳比例参照当地执行标准，公积金5%-12%灵活变通无法律规定。

但实际上这两者会影响每月到手的钱多少... 公积金还好说，社保就见仁见智，不多赘述了。

## 个人所得税计算

### 计算公式

```
应纳税所得额 = 年度收入总额 - 60000元（起征点） - 专项扣除 - 专项附加扣除 - 其他扣除

应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数
```

### 专项扣除

| 项目 | 说明 |
|------|------|
| **基本养老保险** | 个人缴纳部分 |
| **基本医疗保险** | 个人缴纳部分 |
| **失业保险** | 个人缴纳部分 |
| **住房公积金** | 个人缴纳部分 |

### 专项附加扣除

| 项目 | 扣除标准 |
|------|----------|
| **子女教育** | 每个子女每月1000元 |
| **继续教育** | 学历教育每月400元，职业资格教育每年3600元 |
| **大病医疗** | 超过15000元部分，据实扣除，每年最高80000元 |
| **住房贷款利息** | 每月1000元，最长240个月 |
| **住房租金** | 每月800-1500元（按城市级别） |
| **赡养老人** | 独生子女每月2000元，非独生子女分摊每月2000元 |
| **婴幼儿照护** | 每个婴幼儿每月1000元 |

### 综合所得税率表（年度）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|------|------------------|------|------------|
| **1** | 不超过36000元 | 3% | 0 |
| **2** | 超过36000元至144000元 | 10% | 2520 |
| **3** | 超过144000元至300000元 | 20% | 16920 |
| **4** | 超过300000元至420000元 | 25% | 31920 |
| **5** | 超过420000元至660000元 | 30% | 52920 |
| **6** | 超过660000元至960000元 | 35% | 85920 |
| **7** | 超过960000元 | 45% | 181920 |

### 计算示例

**假设**：年度收入20万元，专项扣除3万元，专项附加扣除2万元

```
应纳税所得额 = 200000 - 60000 - 30000 - 20000 = 90000元

应纳税额 = 90000 × 10% - 2520 = 9000 - 2520 = 6480元

税后收入 = 200000 - 30000 - 6480 = 163520元

单月税额也按累进税率计算，采用区间累加方式
```

### 注意事项

| 事项 | 说明 |
|------|------|
| **年度汇算** | 每年3月1日至6月30日进行年度汇算清缴，多退少补 |
| **预扣预缴** | 每月工资由单位代扣预缴，年度汇算时统一计算 |
| **奖金计税** | 全年一次性奖金可选择单独计税或并入综合所得 |
| **免税收入** | 国债利息、保险赔款、福利费等免征个人所得税 |

## 离职证明

### 法律依据

《劳动合同法》第五十条：用人单位应当在解除或者终止劳动合同时出具解除或者终止劳动合同的证明，并在十五日内为劳动者办理档案和社会保险关系转移手续。

### 离职证明必须包含的内容

根据《劳动合同法实施条例》第二十四条，离职证明应当写明：

| 序号 | 必备内容 | 说明 |
|------|----------|------|
| **1** | **用人单位基本信息** | 名称、地址、联系方式 |
| **2** | **劳动者基本信息** | 姓名、身份证号、岗位 |
| **3** | **劳动合同期限** | 起止日期 |
| **4** | **工作期限** | 实际入职到离职的时间 |
| **5** | **解除或终止日期** | 劳动关系结束的具体日期 |
| **6** | **工作岗位** | 在职期间的工作职务 |
| **7** | **解除或终止原因** | 协商解除、辞职、辞退、合同到期等 |
| **8** | **经办人及盖章** | 经办人签字、单位公章 |

### 离职证明中不合法的内容

以下内容写在离职证明上是**不合法**的：

| 序号 | 违规内容 | 法律依据 | 原因 |
|------|----------|----------|------|
| **1** | **负面评价**（如"工作能力差"、"被开除"） | 《劳动合同法实施条例》第二十四条 | 离职证明只能写法定内容，不得包含主观评价 |
| **2** | **双方纠纷或争议** | 《劳动合同法》第五十条 | 离职证明用途是证明劳动关系结束，不是纠纷记录 |
| **3** | **竞业限制条款** | 《劳动合同法》第二十三条、二十四条 | 竞业限制应单独签署协议，不应写入离职证明 |
| **4** | **保密义务条款** | 《劳动合同法》第二十三条 | 保密义务应单独约定，不应写入离职证明 |
| **5** | **违约金或赔偿要求** | 《劳动合同法》第二十五条 | 除培训和竞业限制外，不得约定违约金 |
| **6** | **"非正常离职"等歧视性表述** | 《就业促进法》第三条 | 侵犯劳动者平等就业权 |
| **7** | **员工个人隐私信息** | 《个人信息保护法》 | 如家庭情况、健康状况等无关信息 |
| **8** | **强制要求放弃权益的声明** | 《劳动合同法》第二十六条 | 免除单位法定责任、排除劳动者权利的条款无效 |
| **9** | **"因个人能力原因"等离职原因** | 《劳动合同法实施条例》第二十四条 | 离职证明只需写明法定内容，"因个人能力原因"属于负面评价，侵犯劳动者再就业权 |


#### 常见的违法离职原因表述

| 违法表述 | 问题分析 |
|----------|----------|
| **"因个人能力原因"** | 主观评价，暗示能力不足 |
| **"不能胜任工作"** | 负面评价，影响再就业 |
| **"因违纪离职"** | 带有惩罚性，侵犯名誉权 |
| **"被辞退"** | 歧视性表述，影响求职 |
| **"工作态度差"** | 主观评价，无法律依据 |
| **"未通过试用期"** | 负面评价，影响再就业 |

#### 正确的离职原因表述

| 情形 | 正确表述 |
|------|----------|
| **主动辞职** | "个人原因离职"或"劳动者提出解除劳动合同" |
| **协商解除** | "协商一致解除劳动合同" |
| **合同到期** | "劳动合同期满终止" |
| **单位辞退** | "用人单位提出解除劳动合同"（无需写明具体原因） |

#### 维权方式

| 情形 | 维权方式 |
|------|----------|
| **离职证明已写"因个人能力原因"** | 要求单位重新出具，删除该表述 |
| **单位拒绝修改** | 向劳动监察部门投诉 |
| **已造成损失** | 申请劳动仲裁，要求赔偿实际损失 |
| **影响新单位入职** | 主张赔偿失业期间工资损失 |

#### 实用建议

1. **收到离职证明时当场核对**：发现"因个人能力原因"等表述，当场要求修改
2. **拒绝签字**：对不合规的离职证明拒绝签字接收
3. **保留证据**：保留原件、沟通记录、拒收证据
4. **及时维权**：发现问题及时投诉或仲裁，不要拖延

### 如何保护自己权益

#### 1. 离职前准备

| 步骤 | 具体操作 |
|------|----------|
| **书面提交离职申请** | 保留提交证据（邮件、快递回执等） |
| **工作交接清单** | 列明交接事项，双方签字确认 |
| **确认工资结算** | 包括加班费、年假、奖金等 |
| **索要离职证明** | 明确要求单位在15日内出具 |

#### 2. 核对离职证明

收到离职证明后，重点核对：

- ✅ 单位名称、地址是否准确
- ✅ 个人信息（姓名、身份证号）是否正确
- ✅ 入职和离职日期是否准确
- ✅ 工作岗位是否准确
- ✅ 是否加盖单位公章
- ❌ 是否有负面评价或歧视性内容
- ❌ 是否有竞业限制、保密等附加条款
- ❌ 是否有"非正常离职"等不实表述

#### 3. 发现问题时的维权途径

| 问题 | 维权方式 | 法律依据 |
|------|----------|----------|
| **单位拒不开具离职证明** | 向劳动监察部门投诉，要求限期出具 | 《劳动合同法》第八十九条 |
| **离职证明内容不实** | 要求更正，拒不更正的可申请劳动仲裁 | 《劳动合同法》第八十九条 |
| **包含负面评价** | 要求删除，可主张名誉权受损赔偿 | 《民法典》第一千零二十四条 |
| **包含不合法条款** | 主张该条款无效 | 《劳动合同法》第二十六条 |
| **造成损失** | 要求赔偿（如影响新单位入职） | 《劳动合同法》第八十九条 |

### 赔偿预估

| 情形 | 赔偿金额 |
|------|----------|
| **拒不开具离职证明** | 赔偿实际损失（如新单位无法入职的工资损失） |
| **离职证明内容不实造成损失** | 赔偿实际损失 + 精神损害赔偿（如有） |
| **包含负面评价造成名誉损害** | 删除不实内容 + 赔礼道歉 + 精神损害赔偿 |
| **因离职证明问题影响就业** | 赔偿失业期间的工资损失（按原工资计算） |

### 离职证明丢失能否要求重开

**可以要求重开**。离职证明丢失后，劳动者有权要求原单位重新出具。

#### 法律依据

《劳动合同法》第五十条并未限制单位出具离职证明的次数，只要劳动者确实曾在该单位工作，单位就有义务配合出具证明。

## 休病假不被同意的场景

### 法律依据

**《劳动合同法》第四十二条**：劳动者患病或者非因工负伤，在规定的医疗期内的，用人单位不得依照第四十条、第四十一条的规定解除劳动合同。

**《企业职工患病或非因工负伤医疗期规定》**：企业职工因患病或非因工负伤，需要停止工作医疗时，根据本人实际参加工作年限和在本单位工作年限，给予3个月到24个月的医疗期。

### 合法病假不被同意的常见场景

| 场景 | 单位做法是否合法 | 说明 |
|------|------------------|------|
| **提供正规医院病假条，单位拒绝批假** | ❌ 违法 | 单位必须批准符合规定的病假 |
| **以"人手不足"为由拒绝病假** | ❌ 违法 | 人手不足不能成为拒绝病假的理由 |
| **以"试用期"为由拒绝病假** | ❌ 违法 | 试用期员工同样享有病假权利 |
| **以"业务繁忙"为由拒绝病假** | ❌ 违法 | 业务原因不能剥夺员工病假权利 |
| **要求必须到指定医院看病** | ⚠️ 部分合法 | 一般应认可正规医院证明，指定医院需合理 |
| **病假条手续不全要求补齐** | ✅ 合法 | 单位有权要求提供完整的病假证明 |
| **怀疑病假条真伪要求复核** | ✅ 合法 | 单位有权核实病假条真伪 |
| **超出医疗期拒绝续假** | ✅ 合法 | 超过法定医疗期单位可不再批病假 |

### 医疗期规定

| 工作年限 | 本单位工作年限 | 医疗期 |
|----------|----------------|--------|
| **不满10年** | 不满5年 | 3个月 |
| **不满10年** | 满5年及以上 | 6个月 |
| **满10年及以上** | 不满5年 | 6个月 |
| **满10年及以上** | 5年至不满10年 | 9个月 |
| **满10年及以上** | 10年至不满15年 | 12个月 |
| **满10年及以上** | 15年至不满20年 | 18个月 |
| **满10年及以上** | 满20年及以上 | 24个月 |

### 病假工资计算

| 项目 | 规定 |
|------|------|
| **病假工资基数** | 按劳动合同或单位规章制度确定，一般不低于当地最低工资的80% |
| **病假工资比例** | 根据工龄确定，一般为工资的60%-100% |
| **最低保障** | 病假工资不得低于当地最低工资标准的80% |

**示例**（以某地为例）：

| 工龄 | 病假工资比例 |
|------|--------------|
| 不满2年 | 本人工资60% |
| 2年-4年 | 本人工资70% |
| 4年-6年 | 本人工资80% |
| 6年-8年 | 本人工资90% |
| 8年及以上 | 本人工资100% |

### 单位拒绝病假的应对方法

#### 1. 保留证据

| 证据类型 | 具体内容 |
|----------|----------|
| **病假证明** | 正规医院出具的病假条、诊断证明 |
| **就医记录** | 挂号单、病历、检查报告、处方 |
| **沟通记录** | 与主管/HR的微信、邮件、录音 |
| **提交记录** | 病假申请截图、提交时间记录 |
| **公司制度** | 员工手册、考勤制度中关于病假的规定 |

#### 2. 应对步骤

| 步骤 | 具体操作 |
|------|----------|
| **1. 书面申请** | 通过邮件或书面形式提交病假申请，附病假条 |
| **2. 保留凭证** | 保留所有提交证据和沟通记录 |
| **3. 按时就医** | 按医嘱休养，保留就医记录 |
| **4. 书面沟通** | 单位拒绝时，书面要求说明拒绝理由 |
| **5. 投诉举报** | 向劳动监察部门投诉（12333） |
| **6. 申请仲裁** | 如造成损失，申请劳动仲裁维权 |

### 赔偿预估

| 情形 | 赔偿金额 |
|------|----------|
| **病假期间被扣工资** | 补发病假工资（不低于最低工资80%） |
| **病假期间被辞退** | 违法解除赔偿金 2N（按工作年限计算） |
| **因未批病假导致病情加重** | 赔偿医疗费、误工费等实际损失 |
| **因病假被拒被迫离职** | 经济补偿金 N + 可能的额外赔偿 |

**示例计算**：
- 工作年限3年，月薪10000元
- 病假被拒导致被迫离职：经济补偿金 = 3 × 10000 = **30000元**
- 病假期间被违法辞退：赔偿金 = 2 × 3 × 10000 = **60000元**

### 注意事项

- ✅ **病假条必须真实**：伪造病假条可被合法辞退，且不赔偿
- ✅ **及时提交申请**：尽可能提前或当天提交病假申请
- ✅ **遵守公司流程**：按公司规定的流程请假，但公司流程不能违反法律
- ❌ **不要旷工**：即使单位不批病假，也不要直接旷工，应书面说明情况
- ❌ **不要伪造证明**：伪造病假条属于严重违纪，可被合法辞退
- ⚠️ **医疗期内保护**：医疗期内单位不得以"不能胜任工作"等理由辞退员工

## 离职后工资发放对不上如何处理

### 第一步：先搞清楚「对不上」的原因

先把少发的钱**拆到具体科目**，避免笼统地说「工资少了」。和公司人力/财务逐条对账：

| 常见「少发」原因 | 合法吗？ | 说明 |
|-----------------|----------|------|
| **社保公积金个人部分代扣** | ✅ 合法 | 在职最后一个月正常扣，和之前每个月一样 |
| **个税代扣** | ✅ 合法 | 按累计预扣法或单独计税，扣得多可能是当年总收入跳档了 |
| **未出勤/请假扣款** | ✅ 合法（有依据） | 按考勤表据实扣，需公司提供考勤记录 |
| **绩效/奖金扣发** | ⚠️ 看证据 | 公司必须拿出考核评分依据和规章制度 |
| **餐补/交通补/全勤奖等取消** | ⚠️ 看合同 | 需劳动合同或员工手册有约定，不能临时口头取消 |
| **加班工资未发** | ❌ 违法 | 有加班证据（考勤/群消息/审批单）必须发 |
| **未休年假折算工资** | ❌ 违法 | 未休年假要按日工资的 300% 算（其中1倍是正常工资，补发差额2倍）|
| **代通知金或补偿金未发** | ❌ 违法 | 公司无过失性辞退应付N+1，其中+1是代通知金 |
| **「离职员工不发」的各种补贴** | ❌ 违法 | 在职期间产生的业绩提成、年终奖、季度奖，不能因离职不发（需符合发放条件） |

> 💡 **关键动作**：让公司人力给你一份**离职结算清单**（书面的，盖公章或电子签更好），列明清扣了每一笔是什么、依据是什么。没有书面清单，先不要签字或确认。

### 第二步：自己算一遍「应该拿到多少」

按以下公式核对：

```
应发工资 = 月基本工资 ÷ 21.75 × 实际出勤天数
        + 绩效工资/提成（符合条件部分）
        + 加班工资（1.5倍/2倍/3倍）
        + 未休年假折算工资（日薪×200%×未休天数）
        - 社保公积金个人部分
        - 个税
        - 合法的考勤扣款
```

**核心公式速查**：

| 项目 | 计算公式 |
|------|----------|
| **日工资** | 月工资 ÷ 21.75 |
| **小时工资** | 月工资 ÷ 21.75 ÷ 8 |
| **工作日加班** | 小时工资 × 1.5 × 加班小时数 |
| **周末加班** | 小时工资 × 2 × 加班小时数（或调休） |
| **法定节假日加班** | 小时工资 × 3 × 加班小时数（不能调休抵） |
| **未休年假折算** | 日工资 × 200% × 未休天数（额外补的部分） |

### 第三步：什么时间发才合法？

| 情况 | 法律规定时间 |
|------|-------------|
| **一般规定** | 解除或终止劳动合同**当日**一次性付清（部分省份规定）|
| **约定按正常发薪日** | 多数地区允许和公司约定按原发薪日发放（比如每月15号）|
| **超过约定时间没发** | 属于**拖欠工资**，可以直接走劳动监察 |

> 🔴 **超过30天算严重**：原劳动部规定，无正当理由超过约定时间未发，哪怕只晚了一天，就是拖欠工资。

### 第四步：维权步骤（按顺序走）

#### 步骤 1：和公司协商（留书面证据）

```
给人力/主管发消息（微信/邮件/钉钉，不要只口头）：
  「关于我 X月X日 离职的工资结算，实际到账 XXXX 元，
   按照合同约定应为 XXXX 元，差额 XXXX 元具体为：
   - 未休年假 2 天折算：XXXX 元
   - 10月最后一周加班 4 小时：XXXX 元
   请提供书面结算清单，并于 X月X日前补发，
   若未补发，我将申请劳动监察和劳动仲裁。」
```

✅ **必须是书面**，之后这就是证据。对方回复的聊天记录、邮件都要截图保存。

#### 步骤 2：向劳动监察大队投诉（最快，1~2 周见效）

**适合情况**：金额不大、事实清楚（就是少算了加班费或年假折算）。

```
操作：
  1. 打 12333 热线（工作日 9:00-17:00）
  2. 或登录「国家政务服务平台」→ 搜索「劳动保障监察投诉举报」
  3. 或去公司注册地的区/县人社局劳动监察窗口现场投诉

准备材料：
  - 身份证复印件
  - 劳动合同（或考勤/工资条/钉钉记录，能证明劳动关系）
  - 工资到账记录（银行流水截图）
  - 少发金额的计算依据（自己列个表）
```

✅ **劳动监察是行政介入**，公司一般不想被查，很多情况这一步就补了。

#### 步骤 3：劳动仲裁（终极手段，1~2 个月出结果）

**适合情况**：金额大（超过 5000 元）、和公司有争议（比如绩效扣发双方都有道理）。

```
仲裁流程：
  公司注册地 → 劳动人事争议仲裁委员会 → 提交仲裁申请书
                    ↓
  5 日内决定受理 → 开庭 → 调解/裁决（45 日内结案）
                    ↓
  裁决生效后 15 日内公司不执行 → 申请法院强制执行
```

**仲裁请求可以主张的项目**：

| 请求项 | 金额 | 证据 |
|--------|------|------|
| 补发未足额支付的工资/绩效/提成 | XXXX 元 | 结算清单 + 合同约定 |
| 补发加班工资 | XXXX 元 | 考勤表/打卡记录/加班审批 |
| 补发未休年假折算工资 | XXXX 元 | 年假制度/入职年限证明 |
| 经济补偿金（如因欠薪被迫离职） | N×月薪 | 被迫离职通知书 + 欠薪证据 |
| **加付赔偿金**（欠薪 50%~100%）| 0.5~1×欠薪金额 | 劳动监察责令支付后仍不付，可加主张 |

> ⚠️ **仲裁时效 1 年**：从离职之日算起，超过 1 年法律不保护，尽早行动。

#### 步骤 4：如果还没拿到钱（法院强制执行）

仲裁裁决生效后公司不给 → 去法院申请强制执行，法院会从公司账户直接划扣：

```
准备：仲裁裁决书原件 + 强制执行申请书 + 身份证
  → 公司注册地基层法院立案庭
```

### 第五步：必备证据清单（现在就开始整理）

| 证据 | 作用 | 怎么拿 |
|------|------|--------|
| **劳动合同** | 证明工资标准、岗位、工时 | 自己留存那份 |
| **银行工资流水** | 证明公司实际发了多少 | 银行APP导出/打印盖章 |
| **工资条/薪资截图** | 证明工资结构（基本工资/绩效/补贴） | 公司HR发的截图或邮件 |
| **考勤记录/打卡截图** | 证明出勤和加班 | 钉钉/企业微信截图 |
| **离职证明** | 证明离职时间 | 公司开具 |
| **社保公积金缴费记录** | 证明在职时间和代扣金额 | 支付宝/微信 社保查询导出 |
| **个税 APP 收入明细** | 证明公司申报的税前收入 | 个税 APP → 收入纳税明细查询 |
| **和HR/主管的聊天记录** | 证明协商过程和公司承认的金额 | 原始截图，别只转文字 |

> 💡 **个税 APP 小技巧**：打开「个人所得税」APP → 收入纳税明细查询，看看公司给你申报的「本期收入」是多少。如果申报数 > 实际到手数（扣完社保个税后仍不匹配），说明公司确实少发了，这是铁证。

### 常见陷阱（别踩坑）

| 陷阱 | 公司会怎么说 | 正确应对 |
|------|------------|---------|
| ❌ **签了「无争议确认书」就不能再要了** | 「你都签字确认无任何纠纷了」 | 如果是被胁迫/重大误解/公司欺诈签的，可以撤销；但签字前一定要看清，**有争议别随便签** |
| ❌ **离职员工不发年终奖/提成** | 「公司规定离职不享受」 | 看规章制度，如果是在职期间产生的业绩，符合条件必须按比例发；约定"离职不发"的制度很多地方判无效 |
| ❌ **绩效扣发不需要依据** | 「你考核不合格所以扣绩效」 | 公司必须拿出：① 你签字确认过的考核制度 ② 本次考核的具体评分和依据 ③ 评分过程合理，否则扣发无效 |
| ❌ **年假跨年作废** | 「去年年假没休就没了」 | 年假可以跨一个年度安排；离职时未休的，按日工资300%折算，不存在作废 |
| ❌ **加班费包含在月薪里** | 「合同写了月薪含加班」 | 低于法定加班费标准的部分必须补齐；每月加班超过36小时本身违法 |

### 维权成本和时间总结

| 维权方式 | 耗时 | 金钱成本 | 成功率（事实清楚时） |
|---------|------|---------|---------------------|
| 协商 | 1~5 天 | 0 | 50%（公司理亏时高） |
| 劳动监察 | 1~2 周 | 0 | 70%~80% |
| 劳动仲裁 | 2~3 个月 | 0（不收费）| 85%+（证据充足时） |
| 法院执行 | 1~2 个月 | 0 | 95%（公司正常经营） |
